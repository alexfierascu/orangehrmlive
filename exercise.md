# Coding Exercise — Test Automation

## Requirement

Develop a test framework and implement tests for **OrangeHRM**.

## Instructions

- Write tests against any **1 module** of your choice (e.g. Time, PIM, or the Recruitment module).
- Login details for the OrangeHRM site are on the page itself: <https://opensource-demo.orangehrmlive.com/>
- Preferable language: **JavaScript, TypeScript, or Python**.

## What are we looking for?

- We are **not** looking for complete test coverage, but enough to demonstrate skills and experience — e.g. in PIM, scenarios for "add an employee".
- Make sure the test scenarios and code are clear and demonstrate good practices.
- Include a README file explaining how to build and run the solution.
- Bear in mind that the solution will form the basis for a follow-up conversation.

## Checklist

- A public repository (e.g. GitHub, Bitbucket) containing the test framework and the automated tests.
- A README explaining:
  - How to build and execute the solution.
  - Details on anything further that would be done given more time, including any trade-offs made.
